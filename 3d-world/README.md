# FACECRAFT - 3Dブロックワールド

顔面シューティング本体とは独立した、Three.js製のブラウザ向けボクセルワールド試作です。

## 起動
GitHub Pagesで公開する場合は `/3d-world/` を開きます。Three.jsはjsDelivr CDNから読み込みます。

## 現在の実装
- 3Dブロック地形と簡易な木
- 一人称 / 三人称切り替え
- PCのWASD・マウス操作
- スマホの移動ボタン・画面スワイプ操作
- ブロック破壊・設置、ホットバー
- サバイバル / クリエイティブ切り替え
- ワールド変更のブラウザ内保存

## 今後の開発候補
顔データ連携、チャンク生成、クラフト、敵・動物、ワールドの書き出しと読み込み。
