# FACECRAFT - 顔面シューティング風3D無限ワールド

## 主な機能
- プレイヤー周辺だけを生成する16×16チャンク式の無限地形
- 遠方チャンクのアンロード、InstancedMesh描画
- 一人称 / 三人称、サバイバル / クリエイティブ
- 顔画像を使ったプレイヤーと顔面モンスター
- モンスター追跡・撃破スコア・5体撃破ごとの大型ボス
- 地下洞窟、石炭・鉄・金・ダイヤ鉱石
- 宝箱とランダム戦利品
- 動き回る動物
- 採掘、ブロック設置、8種以上の建築ブロックと鉱石
- 所持品、木材加工、棒、石ツルハシ、インゴット、ダイヤ剣のクラフト
- PC / スマホ操作
- 端末内保存（プレイヤー位置、ブロック編集、所持品、スコア）

## 操作
- PC: WASD移動、マウス視点、Spaceジャンプ
- 左クリック / F: 攻撃・採掘
- 右クリック / E: ブロック設置
- 1〜8: ホットバー選択、V: 視点切替、M: モード切替
- スマホ: 左側ボタンで移動、右側スワイプで視点、画面ボタンで攻撃・設置

## クラフト
画面上部の「クラフト」からレシピを選択。素材が足りない場合は作成できません。石のツルハシを作ると採掘間隔が短くなり、ダイヤ剣を所持していると敵への攻撃力が上がります。

## 負荷対策
- PCは周囲7×7、タッチ端末は5×5チャンクを読み込み
- チャンク移動時に必要な地形だけ生成
- チャンク単位で描画をまとめ、遠方を破棄
- スマホは影とアンチエイリアスを抑制

## 注意
保存は同じブラウザ・同じ端末のlocalStorageです。クラウド同期やマルチプレイはありません。実機での動作・FPS確認は必要です。
