# FACECRAFT - 顔面シューティング風3Dブロックワールド

## 公開URL
GitHub Pages: `/3d-world/`

## 今回の実装
- プレイヤーの周囲だけを生成・描画する16×16チャンク方式の無限地形
- 遠くのチャンクを自動アンロードして描画負荷を抑制
- 地形を座標ベースで決定し、移動しても同じ場所は同じ地形になる
- 顔面シューティングの顔画像をプレイヤーと敵に表示
- 顔面モンスター、追跡、攻撃、撃破スコア
- 8種類のブロック、設置・破壊、ホットバー
- 一人称 / 三人称、サバイバル / クリエイティブ
- PC / スマホ操作
- ブロック変更とプレイヤー位置を端末内に保存

## 操作
- PC: WASD移動、マウス視点、Spaceジャンプ
- 左クリック / F: 顔面モンスターを攻撃（敵がいない場合はブロック破壊）
- 右クリック / E: ブロック設置
- 1〜8: ブロック選択、V: 視点切替、M: モード切替
- スマホ: 左側ボタンで移動、右側スワイプで視点、画面ボタンで攻撃・設置

## 負荷対策
- チャンク単位のInstancedMeshで描画
- PCは周囲7×7、タッチ端末は5×5チャンクを読み込み
- チャンク移動時のみ生成・破棄
- アンチエイリアスと影をスマホでは抑制

## 注意
ブラウザのlocalStorage保存なので、同じブラウザ・同じ端末内でのみ引き継がれます。実機でのFPS・スマホ動作確認は別途必要です。
